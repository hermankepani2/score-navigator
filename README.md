# Score Navigator
Live app:https://scorenavigator.lovable.app 

Score Navigator is a human-led credit score improvement tracker: the user enters every number, and the app never invents balances, limits, APRs, due dates, or scores. Six screens — Dashboard, Cards, Calendar, Payoff plan, Disputes, Score log — plus a 7-day upcoming-payments list, browser payment reminders, and AI-drafted dispute follow-up letters. Dark, high-contrast, large-print design for low vision. Everything stays in the browser via localStorage, with JSON export/import. Free forever.

An organizer and reminder tool, not financial advice.
